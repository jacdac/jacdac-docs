# Packet Console

The packet console provides a low-level log view over packets being sent and received.
This is an advanced view for understanding how protocol communication is happening.

## Exploring packets

- Open the [device tree](/tools/device-tree/) and click the history icon to open the console.
- Use filters to narrow down which packets to inspect.

## Pause and inspect

- Use the play/pause button to stop updating packets.
- Click any packet to inspect a detailed view of its contents.
