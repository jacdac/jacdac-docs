# Jacdac for MakeCode and the micro:bit

**Posted on June 17th, 2022 by Jacdac Team**

We are delighted to announce the public debut of Microsoft's [Jacdac](https://aka.ms/jacdac) platform for plug-and-play creation and programming of physical computing systems. Jacdac brings three exciting enhancements to MakeCode for the micro:bit V2:

1. **modular accessories** with plug-and-play cables, shown above;
2. **unified coding blocks** for all accessories;
3. **hardware simulators and device twins** for micro:bit accessories.

A [micro:bit V2](/devices/microbit-educational-foundation/microbitv2/) is required for deployment to hardware, as Jacdac needs more resources than available on the original micro:bit. Jacdac is [backward compatible with existing micro:bit accessories](#backward-compatible-with-existing-accessories). If that's enough for you, see our [call to action](#call-to-action) for MakeCode users and micro:bit accessory manufacturers. Otherwise, read on...

[This blog post is cross posted at medium](https://medium.com/@jacdac/jacdac-for-makecode-and-the-micro-bit-887291d60f3c).

## Modular accessories

Jacdac is a hardware+software platform for the plug-and-play creation and programming of physical computing systems. A “brain”, in this case a micro:bit V2, executes the user’s program, while a set of modular accessories, or modules, provide additional capabilities.

### Kittenbot's Jacdac Starter Kit A

[Kittenbot](https://www.kittenbot.cc) is making [Jacdac Starter Kit A with Jacdaptor for micro:bit V2](/devices/kittenbot/jacdacstarterkitawithjacdaptorformicrobitv2v10/), shown at the beginning of the blog and featured in the video above, available for purchase in limited quantity. This first commercially available kit features seven Jacdac modules.

## Unified block coding for accessories

Jacdac provides a large set of [services](/services) to describe the high-level functionality of hardware, both existing micro:bit accessories and new Jacdac modules. The [button service](/services/button), which represents any push button, is one of the simplest Jacdac services.

## Hardware simulators and device twins

From the beginning, a web-based micro:bit simulator has been an essential part of the discovery process for the BBC micro:bit. For almost every service, Jacdac provides a simulator that integrates seamlessly into MakeCode, as well as a device twin that displays the status of a connected accessory.

## Call to action

### MakeCode users

To get started with Jacdac for MakeCode and the micro:bit, users have several options:

- **Jacdac kits available**: see the [device catalog](/devices/).
- **Software for existing accessories**: try out a micro:bit accessory with a [Jacdac MakeCode extension](/ddk/microbit/extension-samples).
- **Jacdac hardware simulators**: try out [Jacdac Projects for MakeCode](/clients/makecode/projects) right away, using Jacdac simulators.

### Micro:bit accessory manufacturers

Jacdac provides manufacturers of micro:bit accessories several options:

- **Software for existing accessories**. We have created a way to add Jacdac support to MakeCode extensions for existing accessories. We have added Jacdac to several MakeCode extensions as [samples](/ddk/microbit/extension-samples). Read more about [software-only Jacdac](/ddk/microbit/software-only-accessory/).
- **Add a Jacdac edge connector to your designs**. It’s inexpensive to add the 3-wire [Jacdac edge connector](/ddk/microbit/#low-powered-physical-connector) to your accessory.
- **Make your own Jacdac modules** using the Jacdac [Device Development Kit](/ddk).
